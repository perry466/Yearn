# 🎂 Yearn · 岁岁念 — 使用指南（中文）

> 这是 **「怎么用」** 的操作手册，面向普通用户。
> 部署 / 接口 / 开发相关内容请看主文档：[README_zh.md](../README_zh.md) ｜ [English](../README.md)

岁岁念是一个带 **农历支持** 的生日提醒应用：录入亲友的生日（公历或农历），它帮你算「还有几天」，并在临近时通过邮件 / Server 酱提醒。

---

## 🚀 本地从零启动（Local Setup）

克隆仓库后，**一条命令就能跑起整个项目** —— 单个后端进程同时提供 API **和** 已构建的
前端，提醒调度也会自动启动。

```bash
git clone https://github.com/perry466/Yearn.git
cd Yearn/backend
pip install -r requirements.txt          # ① 安装后端依赖

cd ../frontend
npm install
npm run build                            # ② 构建 frontend/dist（必做，不在 git 中）

cd ../backend
python run.py                            # ③ 启动 API + 调度 + 托管前端
```

- 打开 **http://localhost:8000**。
- 随时用 `python stop.py`（同一目录）停止。
- ⚠️ `frontend/dist` **被 git 忽略**，clone 后必须跑一次 `npm run build`，否则网页空白。
- 开发时想热更新？可分开跑后端（`uvicorn app.main:app`）和前端（`npm run dev`，端口 `:5173`）。
  详见 [README_zh.md 第三节](../README_zh.md#三、快速启动)。

## 🏠 首页 Home

打开应用默认进入首页。

### 1. 即将到来（横向卡片）
顶部是一条横向滚动的卡片，展示 **最近即将过生日** 的人，每张卡显示姓名、分类、还有几天、下一次生日日期。左右拖动 / 滚动查看。

### 2. 列表 / 卡片视图切换
页面右上角可在 **列表视图** 与 **卡片视图** 之间切换，状态会被记住（刷新不丢失）。

- **列表视图**：每行一条，含姓名、分类徽章、年龄、公历 / 农历日期、倒计时天数。
- **卡片视图**：每张卡片一个头像、姓名、分类、倒计时，更适合大屏。

### 3. 分类筛选
顶部可按分类（家人 / 朋友 / 同事 / 同学 / 客户 / 其他）筛选，只看某一类人的生日。

### 4. 倒计时
每条记录都会实时显示「还有 N 天」。当天生日显示「今天」。

### 5. 分页
记录多时自动分页，分页栏固定在底部，方便连续翻页。每页条数取 3 的倍数（9 / 12 等）。

### 6. 新增生日
点击右上角「＋ 新增生日」按钮，弹出录入弹窗（详见下文）。

## 📅 日历 Calendar

按月展示生日：

- 每个日期格内显示当天过生日的人（姓名 + 小图标）。
- **同时显示农历与公历**：农历生日会在对应农历日高亮，公历生日标注公历日。
- **今日高亮**：当前日期格有特殊底色。
- 底部显示「本月共 N 人」汇总。
- 顶部可切换 上一个月 / 下一个月。

> 农历生日按「月 + 日」换算到当前年，因此每年自动对应到正确的公历日期。

## 📊 统计 Stats

统计页帮助你一眼看清全量数据：

- **概览卡（4 张）**：
  - 👥 **总计** — 全部生日条数
  - 🎂 **30 天内** — 未来 30 天要过生日的人数
  - 📅 **本周** — 未来 7 天内
  - 🎁 **今日** — 今天过生日的人数
- **按分类条形图**：6 个分类的人数对比。
- **分布饼图**：各类别占比（SVG 绘制）。

### 🔍 下钻（Drill-down）
点击 **任意概览卡 / 分类条形 / 饼图扇区或图例**，会弹出该维度下的 **明细记录列表**：

- 性别头像 + 姓名 + 分类徽章 + 年龄 + 公历 / 农历日期 + 倒计时天数。
- 卡片、条形、图例都有 hover 反馈与「点击查看明细」提示。
- 弹窗内可继续浏览，不影响当前页面。

> 下钻完全基于前端筛选，无需新增后端接口。

## ➕ 新增 / 编辑生日

点击「＋ 新增生日」打开录入弹窗，分区如下：

1. **基础信息**：姓名（必填）、性别。
2. **日期选择**：
   - 公历 / 农历 统一分段控件切换。
   - 选农历时：年 + 月 + 日 三列下拉；大月 30 天、小月 29 天动态变化；带 **闰月开关**。
   - 选公历时：日期上限为今天。
3. **分类**：6 个分类以 Emoji 图标网格选择（家人 / 朋友 / 同事 / 同学 / 客户 / 其他）。
4. **备注**：自由文本。
5. **提醒**：是否启用提醒（开关）。

编辑已有记录：在列表 / 卡片里点击该记录即可打开同样的弹窗并预填内容。

## 🌗 公历 / 农历

- **公历生日**：直接选公历日期，每年同一天。
- **农历生日**：切到农历模式选「农历年月日」，应用会换算成每年对应的公历日期来计算倒计时。
- **闰月**：农历闰月通过弹窗里的「闰月」开关标记，确保闰月生日正确换算。

## 🔔 提醒

调度器每天 09:00（Asia/Shanghai）自动检查，并在启动时会立即检查一次，提前 **30 / 15 / 7 / 1 天** 时发送：

- **渠道**：邮件（SMTP）+ Server 酱。
- **去重**：同一人的同一提前窗口不会重复通知。
- **在应用里配置**：打开网页 **「设置 (🔔)」** 页（`/settings`）即可开关渠道、勾选提前天数、编辑消息模板，无需改代码。
- **调度器**：随应用自动启动，无需单独运行。

详见 [README_zh.md 第六节（提醒系统）](../README_zh.md#六提醒系统)。

## 💾 数据与备份

- 数据默认存在后端 `backend/birthday.db`（SQLite），首次启动自动创建。
- 修改表结构后如启动报错，可删除 `birthday.db` 重启（会重建表，已有数据会清空）。
- 演示用测试数据：`backend/reset_100.py`（会清空后随机生成 100 条，**生产勿用**）。

## ❓ 常见问题

- **列表 / 卡片没数据？** 先确认后端已启动（默认 `:8000`），前端代理 `/api` 正常。
- **某天生日没提醒？** 打开 **「设置」(`/settings`)** 检查：渠道已开启且凭据正确、至少勾选了一个提前天数、该记录的「提醒」开关为开。调度器随应用自动启动。
- **更多排查**：见 [README_zh.md 第九节（常见问题）](../README_zh.md#九常见问题)。
